# 出库链路 UI 与操作验证（2026-10-23）

## 实现

- 参考 9–12.png，重做出库首页、拍照出库、语音出库、待确认出库：圆角描边卡片、青绿/蓝色入口、来源标记、批次选择、数量步进、原因与去向、批次及商品余量。
- 拍照/语音数量未识别时留空，支持手动选择库存商品与可用批次；不展示虚构的识别匹配百分比。
- 保存生成未核对草稿；修改数量后重新核对，全部有效且已核对后统一确认出库。库存校验计入其他所有出库草稿的预占数量。
- 新增录入项时清理识别会话，异步旧结果不覆盖新项；相机返回/配置重建保留同一会话，编辑保留原照片附件。
- 调试预览通过 `outbound_preview=true` 显式开启，示例库存、草稿和流水仅在内存中操作，不写入正式 Room 库。

## 模拟器实际操作

设备：Android Studio `YouShu_API35` / `emulator-5554`。
使用 `adb install -r` 替换安装，保留应用数据。以下库存操作均在明确标注的隔离预览内进行。

| 操作 | 实际结果 |
| --- | --- |
| 打开出库首页、拍照、语音、待确认四页 | 路由正常，3 条混合来源示例可编辑，来源与数量显示正确 |
| 拍照页打开批次选择 | 牛奶 3 批可选，分别显示批次、效期、库存和预占提示 |
| 打开重新拍摄及系统相册后取消 | 返回保留当前表单与录入项 |
| 语音页对“苏打饼干2箱，报损，送到报损区”重新分析文字 | 实际服务返回“识别结果已自动填入，请核对表单” |
| 保存后录下一件 | 保存成功后清空商品/数量/当前识别结果并生成新的录入项 |
| 牛奶数量从 6 增至 9（选中批次库存 8） | 显示超过批次库存，阻止保存与确认；未保存变更显示提示 |
| 数量改为 7 并保存 | 已核对数变为 2/3，牛奶重新待核对；显示商品余量 17、该批次余量 1 |
| 全部核对、确认 3 条出库 | 显示“模拟出库完成，库存和流水已更新”，待确认队列清空 |
| 检查确认后的库存 | 牛奶 24→17 瓶；苏打饼干 36→34 箱；方便面 8→7 箱 |
| 检查牛奶批次与流水 | B20261010 剩 1 瓶，商品合计 17 瓶；新增 −7 瓶、补到货架、销售区及操作时间记录 |

本次验证包含真实文本分析请求及相机/相册入口；未将设备麦克风实录、原始商品照片的云端识别描述为已完成的测试。
